## 1️⃣ القرارات التقنية المعتمدة

| البند | القرار | السبب |
| --- | --- | --- |
| **البنية** | **Astro 5 (Site Generator)** | موقع تعليمي مُحتوى أولاً: SEO ونشر ثابت وسرعة فائقة بدون مجهود |
| **المحتوى** | **MDX Content Collections** | كتابة الدروس كملفات مستقلة بدون أي كود — أسهل إدارة وتوسع |
| **التفاعل** | **React Islands (`@astrojs/react`)** | الأدوات التفاعلية (كويز/حاسبات/محاكيات) تُحمَّل فقط عند الحاجة |
| **اللغة** | عربي أساسي + مصطلحات إنجليزية، واجهة ثنائية (RTL/LTR) | جمهور عربي + امتحان بالإنجليزية |
| **التخزين** | **localStorage** (لا حسابات) | بدون سيرفر، أفضل خصوصية، لا تعقيد |
| **الستايل** | **Tailwind CSS 4** | مرة أخرى سريع وموحّد |
| **التحقق** | TypeScript صارم + `astro check` | سلامة الشيفرة |
| **الاستضافة** | Vercel / Netlify / Cloudflare Pages (static) | مجاني وسريع وتلقائي SEO |

**لماذا Astro وليس Next/SPA؟**
- محتوى تعليمي = أولوية النص والوصول، مش كثافة التطبيق.
- الكتابة بالمحتوى في MDX تسمح بتحرير الدروس بدون خبرة برمجية.
- كل صفحة درس تُخرج HTML نقي ⇒ SEO وCore Web Vitals مثاليان تلقائياً.
- الجزيرات تعطي تفاعل جزئي فقط عند الحاجة الحقيقية.

## 1.5️⃣ قابلية التوسع لمسار تعدد الكورسات (منصّة لاحقاً)

> **الرؤية**: المخرج النهائي منصة تعليمية لـ"مجال الصيانة وإدارة المنشآت والأصول" بالكامل، وكورس CFM هو **أول كورس/مسار** فيها — وليس الوحيد.

| القرار الآن | الأثر المستقبلي |
| --- | --- |
| **مفهوم "المسار path" يعامل ككيان أول**: `courseId` في النموذج (سيكون `cfm` إفتراضياً) | إضافة كورسات (CMRP، طاقة، HSE...) بإضافة `courseId` جديد + ملفات محتوى فقط |
| **بنية المحطات والدروس موحّدة في `curriculum.ts`** | أي مسار جديد = جدول بيانات مستقل يعيد استعمال نفس المكوّنات والأدوات |
| **Content Collections قابلة للتوسع** (`courses/` مجلد مستقبل) | الكتابة بالمحتوى دون تغيير الكود |
| **i18n عام** (UI عربي/إنجليزي) | جاهز لأي محتوى لاحقاً |
| **قاعدة Rocketeer: محطة تُبنى كاملة ثم تُنشر قبل التالية** | إطلاق تدريجي فور اكتمال أول المحطات — لا انتظار اكتمال الكورس |

ملاحظة تنفيذية: لا حاجة لإعادة هيكلة الآن؛ فقط **عدم تضمين قرارات مقيدة بـ CFM في الطبقة العامة** (القوالب/البيانات/التصميم). طبقة المحتوى هي التي تحمل اسم الكورس.

## 3️⃣ نموذج المحتوى (Zod Schema في `content/config.ts`)

**Frontmatter للدرس (كل ملف `.mdx`):**
```ts
lesson = z.object({
  id: z.string(),               // lesson-1-1
  station: z.string(),          // station-1
  number: z.string(),           // "1.1"
  title: z.string(),            // عربي
  titleEn: z.string(),          // للإنجليزي
  minutes: z.number(),          // مدة الدراسة التقريبية
  order: z.number(),
  objectives: z.array(z.string()),        // أهداف التعلم
  objectivesEn: z.array(z.string()),
  hasTool: z.boolean(),
  toolName: z.string().optional(),        // اسم الأداة العربي
  toolNameEn: z.string().optional(),
  quizId: z.string().optional(),          // معرف بنك الأسئلة
  sources: z.array(z.string()).optional() // ids من sources.ts
});
```

**Frontmatter للمحطة (`.md`):**
```ts
station = z.object({
  id: z.string(), number: z.number(),
  title: z.string(), titleEn: z.string(),
  description: z.string(), descriptionEn: z.string(),
  badge: z.string(), badgeEn: z.string(),
  icon: z.string(), examWeight: z.number()   // وزن الركن في الامتحان
});
```

**الشرح النظري داخل MDX** = أقسام تبدأ بـ `##` مرقّمة، مع استخدام مكونات Astro جزئية:
```mdx
## ١. أنظمة التبريد والتهوية (HVAC)
<Callout type="myth">
لا يعني "الوقاية" بالضرورة زيادة وتيرة الصيانة!
</Callout>
<Glossary />    <!-- يُرسم تلقائياً من قاموس القسم -->
```

## 4️⃣ إدارة اللغة والاتجاه

- **المحتوى الرئيسي**: عربي مكتوب في MDX مع المصطلحات الإنجليزية **inline** (`**HVAC** — التدفئة والتهوية والتكييف`).
- **واجهة الموقع (UI)**: `ar` افتراضياً مع زر تبديل لـ `en` — عبر `src/i18n/translations.ts` + استدارة `dir="rtl"` على الحاوية.
- **الـ Headings**: عربي مع `titleEn` للـ alternates.
- **الخط العربي**: تضمين خط عربي حديث (مثل IBM Plex Arabic أو Almarai) عبر `@fontsource`.
- **توجيه i18n في Astro**: `<html lang="ar" dir="rtl">` في `BaseLayout.astro`؛ المتغيرات `isRTL` و`language` في context خفيف.

## 5️⃣ نظام التقدم (localStorage)

**مفتاح واحد موحّد:** `cfm-course-progress@v1`

```ts
interface ProgressState {
  completedLessons: string[];               // ids
  quizScores: Record<string, {score, total, completedAt, answers}>;
  mockExam?: { percentage, pillarBreakdown, timeSpent, passed, at };
  bookmarks: string[];
}
```

- **الكتابة**: جزيرة `<ProgressContext>` تضمِّن كل الصفحات (client-synced من `localStorage`).
- **قراءة عند الـ SSG**: المكونات التنقلية تعرض التقدم بعد hydration فقط (منع mismatch بين SSR/CSR).
- **دالة أنيقة للتخزين** (`src/lib/storage.ts`): `load / save / toggleComplete / updateQuiz`.

## 6️⃣ محرك الكويز (Scenario Quiz)

- **بيانات**: ملف `quiz-{lesson}.ts` لكل درس — كل سؤال: `{scenario, question, options[{text, isCorrect, explanation}], difficulty}`.
- **جزرية** `<ScenarioQuiz questions={...} />`:
  - عرض سيناريو واقعي من سياق المنشأة.
  - خيارات 4 مع **كشف فوري** + شرح تفصيلي بعد الاختيار.
  - نتيجة نهائية + حفظ في التقدم + شريط تقدم.
- **نمط أسئلة**: عملي مش نظري (مثال: "أنت مدير منشأة... ما أول قرار صحيح؟").

## 8️⃣ محاكي الامتحان النهائي

- **الكمية**: بنك أسئلة **110+ سؤال** على نمط امتحان CFM (يُوزَّع بوزن الأركان حسب أحدث دليل IFMA الرسمي).
- **المواصفات**: مؤقت تنازلي (المدة بموجب دليل IFMA الرسمي)، مصفوفة أسئلة تنقّل، شطب خيارات خاطئة، وضع علامة للمراجعة، Pause/Resume.
- **التقرير التشخيصي**: نسبة كل ركن، مراجعة الأخطاء، فلترة، وإعادة المحاولة.
- **شهادة إتمام**: عند اجتياز النسبة المعتمدة — قالب طباعة/تحميل مبني حسب اجتياز المحاكي (تنبيه: ليست شهادة رسمية، مجرد تحفيز — مع إخلاء مسؤولية واضح).
- **مكونان**: `MockExamSimulator.tsx` (جلسة) + `ExamReport.tsx` (نتيجة).

## 🔟 SEO + النشر

- **Sitemap & RSS**: مدمجان في Astro (`@astrojs/sitemap`).
- **Structured Data**: حقن `Course`, `LearningResource`, `Quiz`, `FAQPage`, `BreadcrumbList` (JSON-LD في `BaseLayout`).
- **Meta ديناميكي**: عناوين وأوصاف وOG لكل درس/محطة (ناقل بيانات بسيط من content collection).
- **Robots** والـ `noscript` fallback للعناكب غير الـ JS.
- **مبادئ الوصول**: `dir` صحيح، تباين الخطوط، التنقل بلوحة المفاتيح، `aria` في الجزيرات.
- **النشر**: بناء ثابت `npm run build` → استضافة Vercel/Netlify/Cloudflare Pages، مع `sitemap.xml` تلقائي.

## 🔧 مراحل التنفيذ

| المرحلة | النطاق | المخرجات |
| --- | --- | --- |
| **M0 — سكيل المؤسسة** | هيكل Astro + Tailwind + i18n shell + RTL + خط، `curriculum.ts`، `storage.ts` | منصة تعمل وفارغة |
