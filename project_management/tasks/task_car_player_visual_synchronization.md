# خطة ترقية مشغل السيارة (Car Player) ومطابقة الإخراج البصري مع ماستر كلاس YouTube
# Car Player Visual Stage Upgrade & YouTube Synchronization Architecture Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ترقية مسرح العرض البصري (SlideStage) في نظام الاستماع أثناء القيادة (`CarPlayer`) على منصة GridFix ليطابق تماماً الإخراج البصري الفخم، التفكيك التدريجي، ومصفوفة الأنماط الستة المعتمدة في فيديوهات YouTube، ليحصل مستخدم المنصة في سيارته أو مكتبه على نفس التجربة المرئية التفاعلية المتزامنة مع الصوت لحظة بلحظة.

**Architecture:** 
1. **تحديث نمط البيانات (Audio Cues Engine):** مزامنة هيكل مصفوفات `audioCues` لكل درس مع نبضات الشرح التفاعلي (Beats) وأزمنتها الحقيقية.
2. **ترقية مسرح الشرائح (SlideStage.tsx):** دعم خريطة الملاحة العلوية (HUD Minimap)، معادلات منسقة بألوان الرموز المتغيرة، بطاقات المقارنة المنقسمة، ومخططات المنحنيات الستة المتجهة (SVG Vector Curves).
3. **التكيف مع بيئة القيادة (Ergonomics & Driving Modes):** دعم التبديل التلقائي أو اليدوي بين الوضع الليلي عالي الفخامة (AMOLED Dark Slate + Cyan Glow) والوضع النهاري فائق التباين لمقاومة الوهج الشمسي (Daylight High-Contrast Mode).

**Tech Stack:** React 19, TypeScript strict, Tailwind CSS 4, Lucide Icons, Astro Islands.

**Spec Reference:** `docs/VIDEO_PRODUCTION_CONSTITUTION.md` (دستور ومعيار إنتاج الفيديوهات).

---

## Global Constraints

1. **سلامة القيادة وقابلية القراءة السريعة (Glanceability):**
   * الخطوط كبيرة وواضحة جداً (لا تقل عن 18-24px للنصوص الأساسية و32-48px للمعادلات).
   * تقليل التشتيت: شاشة هادئة تبرز المعلومة الحالية فقط (Active Beat) مع خفوت العناصر السابقة.
2. **التزامن الدقيق مع مشغل الصوت (Zero Drift Sync):**
   * انتقال الشريحة في نفس اللحظة التي ينتقل فيها الصوت (`currentTime >= cue.atSeconds`).
3. **ثنائية الوضع (Day / Night Contrast):**
   * الوضع النهاري: تباين ألوان صارم مع خلفيات فاتحة ناصعة ومقروءة تحت أشعة الشمس المباشرة.
   * الوضع الليلي: خلفيات داكنة تمنع إجهاد العين أثناء القيادة الليلية مع توهج ناعم.
4. **التوافق التام مع TypeScript و Astro:**
   * الحفاظ على بوابات التحقق (`npm run check` و `npm run test` و `npm run qa:ar`) بنسبة 100% نجاح.
