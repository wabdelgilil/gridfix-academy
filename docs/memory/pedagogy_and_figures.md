# الأسلوب العلمي وهندسة الرسوم التوضيحية

> **المجال:** منهجية إعداد دروس وأدوات GridFix Academy لمطابقة متطلبات شهادة CFM.

## 1. قاعدة أسلوب الشرح: المادة العلمية أولاً

1. **المادة هي الهيكل الأساسي:** يُبنى الدرس على المفاهيم الهندسية والإدارية المباشرة التي تغطي كفاءات CFM الإحدى عشرة، بعناوين واضحة وتسلسل منطقي متدرج.
2. **الأمثلة أدوات إيضاح:** تُستخدم الأمثلة العملية لتقريب المفهوم المجرد فقط، ولا يُبنى الدرس على شكل سرد روائي أو تمثيل شخصيات.
3. **الخلاصة نص علمي مكثف:** تُصاغ الخلاصة التنفيذية لكل درس بحيث يمكن قراءتها وفهمها بذاتها دون الرجوع للأمثلة.
4. **المصطلحات بالصيغة المزدوجة الموثّقة:** عند الورود الأول لأي مصطلح تخصصي، يُكتب الاسم العربي متبوعاً بالمصطلح الإنجليزي الرسمي المعتمد بين قوسين — مثل: «تكلفة دورة الحياة (Life Cycle Cost - LCC)».
5. **التوجيه الامتحاني:** يُشار لنمط أسئلة CFM وتطبيقاتها كإضاءة موجهة في نهاية البنود ذات الصلة دون تحويل الدرس إلى مجرد تسريب امتحاني.

## 2. قواعد الرسوم التوضيحية (Visual Figures)

الرسم وجد لخدمة الفكرة المجردة لا للتزيين الشكلي. يُعتمد المكون المناسب من `src/components/ui/figures/` حصراً:

| نوع الفكرة / البنية المعرفية      | المكون المعتمد                 | الغرض                                                |
| :-------------------------------- | :----------------------------- | :--------------------------------------------------- |
| تسلسل خطوات أو مسار قرار          | `FlowChart`                    | رسم شجرة القرار أو تسلسل الإجراءات التشغيلية.        |
| مراحل زمنية أو دورة مستمرة        | `Timeline` أو `LifecycleCycle` | خطة الصيانة، دورة حياة الأصل، مراحل المشروع.         |
| تصنيفات أو أركان أو استراتيجيات   | `Infographic`                  | شبكة تصنيف الأنظمة أو أنواع عقود الصيانة.            |
| علاقات هرمية أو هيكل تنظيمي       | `Hierarchy`                    | هيكل إدارة المرافق، مصفوفة المسؤوليات.               |
| مقارنة بين خيارين أو استراتيجيتين | `Comparison`                   | مقارنة الصيانة الوقائية بالصيانة التنبؤية، عقود NNN. |
| نسب وأرقام وأوزان كفاءة           | `StatGrid`                     | أوزان محاور CFM، مقاييس KPI، مؤشرات EUI.             |

### ضوابط استخدام الرسوم:

- منع استخدام أي SVG يدوي خارجي أو صور عشوائية.
- ملء المكون ببيانات حقيقية مستمدة مباشرة من صلب الدرس.
- وضع الرسم مباشرة بعد الفقرة التوضيحية التي تمهد له.
