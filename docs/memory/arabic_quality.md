# قاعدة جودة العربية — المعيار اللغوي الإلزامي

> **المجال:** منصة GridFix Academy التعليمية (`gridfix.net`)  
> **المرجع:** `scripts/qa-arabic.mjs`

كل النصوص (دروس، كويزات، أدوات، صفحات، خطط، تقارير) يجب أن تكون عربية أصيلة وسليمة تماماً وخالية من أي تشوهات لغوية.

## 1. القواعد الصارمة وغير القابلة للتفاوض

1. **ممنوع "كلمات الآلة" نهائياً:**
   - يمنع استخدام كلمات عربية غير موجودة أو ألفاظ مشوهة تولدها نماذج الذكاء الاصطناعي (أمثلة مرصودة سابقاً: "الحماس"، "ميليء"، "ابيبيل"، "لبساب"، "الغيباب"، "التنرية").
   - كل كلمة يجب أن تكون فصيحة، ذات معنى حقيقي، ومستخدمة في السياق الفني والهندسي الصحيح.
2. **ممنوع خلط الحروف اللاتينية الملتصقة:**
   - لا يجوز دمج أحرف إنجليزية وعربية في كلمة واحدة ملتصقة (مثل: "بمغritaje").
   - المصطلحات الإنجليزية تُفصل بمسافات نظامية أو توضع داخل أقواس: "نظام HVAC"، "عائد الاستثمار (ROI)".
3. **ممنوع الرموز المشوّهة:**
   - يمنع وضع فواصل زخرفية مشوهة مثل `====` أو `==>` أو علامات ترقيم متكررة عشوائياً.
4. **دقة الهمزات والتشكيل والتاء المربوطة:**
   - التمييز الصارم بين همزة القطع وهمزة الوصل (أي/إي، أ/ا).
   - التمييز الصارم بين التاء المربوطة (ة) والهاء (ه) والألف المقصورة (ى) والياء (ي).
5. **المصطلحات الإنجليزية الفنية المعتمدة:**
   - الاختصارات المعتمدة: `HVAC`, `CMMS`, `CAFM`, `SLA`, `ROI`, `LCC`, `IFMA`, `CFM`, `FMP`, `OSHA`, `NFPA`, `ASHRAE`, `LEED`, `ISO`, `KPI`, `EUI`, `IEQ`, `IAQ`, `NNN`, `CO₂`.
   - كل مصطلح جديد يشرح بصيغة مزدوجة عربي/إنجليزي في القاموس.

## 2. بروتوكول التحقق الثنائي (Dual Verification Mandate)

- **التحقق الآلي:** تشغيل أمر `npm run qa:ar` لفحص التعبيرات الشاذة وقائمة `GARBLED_WORDS` في السكربت.
- **المراجعة اليدوية:** القراءة الفاحصة الإلزامية لكل سطر من قبل المهندس/الوكيل؛ لأن السكربت لا يعوض الفهم البشري للألفاظ التي تبدو صحيحة صياغة لكنها ركيكة أو مضللة سياقاً.
- عند رصد أي لفظ غريب، يجب إضافته فوراً إلى مصفوفة `GARBLED_WORDS` في `scripts/qa-arabic.mjs`.
